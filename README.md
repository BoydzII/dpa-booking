# จองคิว DPA · KruSpace

แอปนัดเจ้าหน้าที่ช่วยลงข้อมูล DPA และยื่นขอมี/เลื่อนวิทยฐานะ ใช้บัญชี Google และรายชื่อครู (`staff`) ของ KruSpace (Firebase `pakchongallinone`)

- เจ้าหน้าที่ 4 คน — แอดมินเลือกจากรายชื่อครูทั้งหมด (แท็บ “ตั้งค่า”) พร้อมเบอร์โทรติดต่อด่วน
- เจ้าหน้าที่ประกาศช่วงว่าง (แท็บ “งานเจ้าหน้าที่”) วันทำการ 08:30–16:30 คิวละ 1 ชม. ล่วงหน้าสูงสุด 6 เดือน คัดลอกไปทุกสัปดาห์ได้
- ครูเลือกเจ้าหน้าที่/วัน/เวลา แล้วกดจอง → เจ้าหน้าที่กดรับหรือปฏิเสธ → ครูเห็นสถานะใน “คิวของฉัน”
- ครูมีคิวที่ยังใช้งานอยู่ได้พร้อมกัน 2 คิว (แอดมินปรับได้) จองล่วงหน้าอย่างน้อย 1 วัน

## พัฒนา
```
node tools/build.cjs      # รวม src/* เป็น index.html (ไฟล์ที่สร้าง ห้ามแก้ตรง)
node tools/selftest.cjs   # ทดสอบตรรกะใน src/core.js
```
ดูตัวอย่างในเครื่อง: `preview_start dpa-booking` (พอร์ต 4181) — บน localhost เริ่มใน **โหมดทดลอง** เก็บข้อมูลจำลองในเบราว์เซอร์ ไม่แตะ Firestore จริง

## ก่อนใช้งานจริง
1. วางกติกาจาก `firestore.rules.addition.txt` ใน Firebase Console → Firestore → Rules แล้วเผยแพร่
2. เผยแพร่ทั้งโฟลเดอร์ (index.html, config.js, vendor/) บน GitHub Pages (โดเมน `boydzii.github.io` อยู่ใน Authorized domains แล้ว)
3. เข้าด้วยบัญชีแอดมิน → “ตั้งค่า” → เลือกเจ้าหน้าที่ 4 คน → บันทึก
4. เจ้าหน้าที่เข้าแท็บ “งานเจ้าหน้าที่” ลงช่วงว่าง

หมายเหตุ: ข้อจำกัดล่วงหน้า 1 วัน/6 เดือน/วันหยุดตรวจฝั่งแอป ส่วน Firestore rules คุมเรื่องสิทธิ์และสถานะ ไม่คุมวันที่ การแจ้งเตือนตอนนี้เป็นในแอป (ยังไม่มี LINE/push)
